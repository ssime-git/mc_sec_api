OAuth2 Flow Demonstration

Step 1: Start OAuth Flow

When you click the login button below, the following will happen:

  1. You'll be redirected to the Authorization Server (localhost:5050)
  2. The request will include:
    client_id: "myclient"
    redirect_uri: "http://localhost:5052/callback"
Login with OAuth2

Step 2: Authorization Server Response

The Authorization Server will:

  1. Validate the client_id and redirect_uri
  2. Generate an authorization code
  3. Redirect back to our callback URL with the code

Step 3: Token Exchange

Our application will:

  1. Receive the authorization code
  2. Send it back to the Authorization Server with:
    client_id: "myclient"
    client_secret: "mysecret"
    auth_code: "[received_code]"
  3. Receive and store the access token

Step 4: Success!

If everything works:

  1. We'll have an access token stored in the session
  2. This token can be used to access protected resources
  3. The token will be valid for 1 hour
